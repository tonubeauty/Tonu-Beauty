তনু বিউটি পার্লার - GitHub Pages ডিপ্লয়মেন্ট

যদি এই স্ক্রিনটি দেখা যায়, তবে এর মানে GitHub Pages সোর্স ফাইল লোড করছে। এটি সমাধান করার ২টি সহজ উপায় রয়েছে:

পদ্ধতি ১ (স্বয়ংক্রিয় GitHub Actions - সেরা পদ্ধতি):
১. আপনার GitHub Repo-এর Settings > Pages-এ যান।
২. Build and deployment > Source ড্রপডাউনে "GitHub Actions" সিলেক্ট করুন।
৩. Actions ট্যাবে গিয়ে ডিপ্লয়মেন্ট সম্পন্ন হওয়া পর্যন্ত ১ মিনিট অপেক্ষা করুন।

পদ্ধতি ২ (ব্রাঞ্চ ডিপ্লয়মেন্ট):
১. Settings > Pages-এ "Deploy from a branch" রাখা অবস্থায় ফোল্ডার হিসেবে /docs সিলেক্ট করে Save করুন।
